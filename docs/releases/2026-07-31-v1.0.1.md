# QQ 违规记录机器人 v1.0.1 更新记录

发布日期：2026-07-31

## 更新内容

本次更新改进“新增违规记录格式不完整或字段不明确”时的回复。机器人会保留已经可靠识别的内容，按统一顺序生成一条可复制记录，并把需要用户补充的部分显示为尖括号占位符。

纠正回复会一次列出当前已经确定的全部问题，包括：

- 分区缺失或无效；
- 目标成员信息不足；
- 昵称无法唯一确定而需要 QQ号；
- 时间缺失或无法解析；
- 违规行为、处理措施缺失或不明确；
- 已明确由其他人处理，但处理人身份不明确。

## 使用示例

### 示例一：缺少 QQ号和时间

用户输入：

```text
小明 蜂巢 刷屏 禁言 企鹅处理
```

当“小明”无法唯一匹配时，旧版本只会返回简短错误或候选提示。v1.0.1 会返回可复制的纠正行：

```text
蜂巢 小明（<QQ号>） <时间，24小时制，如03:30或15:30> 刷屏，禁言，企鹅处理
```

### 示例二：缺少分区和处理措施

用户输入：

```text
小明（123456）15:30 刷屏
```

v1.0.1 会返回：

```text
<分区：蜂巢/蜂窝/蜂箱> 小明（123456） 15:30 刷屏，<处理措施>
```

用户只需替换尖括号内的内容后重新发送。

## 字段规则

- QQ号为条件必填。昵称能够按原有规则唯一匹配时，仍可省略 QQ号。
- 时间使用 24 小时制，例如 `03:30` 或 `15:30`；非当天记录应补充日期。
- 回复或引用消息且系统已取得有效消息时间时，继续自动填充时间。
- 记录人继续自动取当前消息发送者。
- 未填写处理人时，继续默认处理人等于记录人。
- 未填写备注时，继续默认为“无”。
- 证据图片继续保持当前提醒模式，不因本次更新改变。

## 兼容性边界

本版本只调整新增违规记录失败时的纠正回复和校验顺序，不修改：

- NLP 意图分类和字段抽取规则；
- 昵称模糊搜索算法、阈值和候选结果；
- 成员查询、分区查询、排序和历史记录输出；
- 正常新增记录的预览、确认、取消和入库结果；
- 旧记录与证据图片展示；
- 数据库结构和目标群处理范围。

格式纠正路径在管理员同步、成员创建、数据库状态检查和待确认写入之前返回，不会产生业务数据。

## 回滚说明

本版本没有数据库迁移。若纠正模板出现异常，可将程序代码回滚到 `v1.0.0` 并只重启 `qq-violation-bot.service`；现有数据库、历史记录和证据文件无需回滚。NapCat 不需要重启。
