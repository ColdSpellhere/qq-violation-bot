# v1.0.2.7beta 发布说明

发布日期：2026-08-18

## 单账号私聊测试

新增独立 OneBot V11 私聊插件。生产环境只允许 `.env` 中配置的一个测试账号，其他私聊事件在 AI 调用前静默过滤。真实允许账号不进入代码、公开文档或 Git 历史。

```dotenv
PRIVATE_CHAT_ENABLED=true
PRIVATE_CHAT_ALLOWED_USER_ID=<私有测试账号>
```

- 允许账号的每条非空普通文字都会回复，不使用群聊 3% 概率。
- `/` 开头命令、空消息和没有文字的图片消息忽略。
- 私聊使用萝卜猫人格，并明确按一对一对话生成，不使用群聊接话提示。
- 最近 20 条双方文字只保存在进程内存，服务重启后清空。
- 每次成功私聊回复仍有 20% 概率附带一张表情包；指定首图在已决定附图时占 10%，其余图片均分 90%。

## 隔离边界

私聊插件不执行查询、记录、减数、禁言或其他群业务，不写群聊归档、成员记忆、违规数据库或本地私聊文件。AI、表情包和 OneBot 发送异常只记录错误类型，不回显内部错误，也不影响群聊服务。

## 快速关闭

将以下配置改为 `false` 并重启机器人服务：

```dotenv
PRIVATE_CHAT_ENABLED=false
```

关闭私聊入口不会改变普通群聊概率、非业务点名开关、成员记忆或任何违规业务。本版本无数据库迁移；代码回滚可切回 `v1.0.2.6beta`。
