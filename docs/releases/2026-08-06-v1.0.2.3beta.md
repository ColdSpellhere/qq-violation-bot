# QQ 违规记录机器人 v1.0.2.3beta 更新公告

发布日期：2026-08-06

版本性质：公开测试版

## 本次更新

- 随机群聊默认概率调整为 5%。
- 上下文能够识别说话者、艾特对象和引用对象，不再默认把群友之间的话理解为对机器人说。
- 按 QQ号建立保守成员记忆，保存昵称、有限历史别名和本人明确表达的稳定非敏感特性。
- 每条 AI 特性必须带有同一成员的原始消息 ID 和逐字引句；没有可靠证据时不写入。
- 机器人无法判断对话对象或没有自然接话点时继续静默。

## 数据与隐私

- 结构化记忆保存在聊天归档数据库的独立 `member_memories` 表。
- 服务器在 `data/member_memory/<群号>/<QQ号>.json` 生成仅 root 可读写的档案镜像。
- GitHub 只包含代码、目录说明和忽略规则，不包含真实成员档案。

## 兼容性与回滚

- 不修改违规记录、证据、管理员、减数策略或 NapCat 数据。
- 记忆提炼或文件镜像失败不会阻断消息归档和既有业务处理。
- 可关闭随机聊天或切回 `v1.0.2.2beta`；新增表和 JSON 可保留，旧版本不会读取。
