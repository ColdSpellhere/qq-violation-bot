# 成员摘要超长的有界纠正

成员摘要在合并较长的旧摘要与新增事实时，可能连续超过既有的 300 字符上限，导致摘要水位停留在原位置。提示现在明确总字符数包含标点与空白，目标为 180～220 字符，保留原有的去除首尾空白后 300 字符硬上限。

只有首次返回的摘要超长且不含秘密时，才允许一次纠正。纠正请求复用首次构造的原始摘要与事实输入，仅增强精简指令，不携带、记录或持久化被拒绝的模型正文。不截断输出，也不强制提交。第二次仍超长时返回 `member_summary_too_long`，摘要与水位保持不变。

每批摘要处理至多调用两次逻辑生成 `_complete`。共享网关的既有传输重试不变，每次逻辑生成最多三次 HTTP 尝试，因此单批处理极端情况下最多六次 HTTP 尝试；持久队列仍最多处理三次，不改变业务意图请求的策略。这个上限不代表后台以后收到新事实时永远不再处理同一成员。

空值、无效类型、秘密内容、请求异常和取消不会触发纠正。已有权限回调在每次逻辑生成前以及提交前继续检查；事实版本和摘要水位的并发校验保持不变。没有数据库迁移或新增配置。

本地行为回归使用合成事实、临时数据库和假的模型响应，覆盖一次成功、纠正成功、两次超长、秘密拒绝、取消、权限关闭、字符计数、并发版本冲突，以及三次队列处理共六次逻辑生成的上限；不发送 QQ 消息，不请求真实模型。
