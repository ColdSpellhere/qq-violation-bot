# QQ 违规记录机器人 v1.0.3 更新公告

发布日期：2026-08-18

版本性质：正式版

`v1.0.3` 将 `v1.0.2beta` 至 `v1.0.2.7beta` 的在线验证成果统一收拢为稳定版本。现有违规记录、证据文件和运行配置保持兼容；从最后一个 beta 升级不需要迁移业务数据。

## 违规记录与查询

- 修复 `查询 <群> <名字>` 在昵称未匹配时错误返回该群最近 20 条记录的问题，未找到时只发送一条提示。
- 两条及以上查询结果使用 QQ 合并转发，每条记录及其证据图片位于同一节点，避免逐条刷屏。
- 合并转发失败时只降级为一条合并文字，不会重新逐条发送记录和图片。
- “帮助”升级为分组管理手册，补全查询、新增记录、禁言、状态维护、减数策略和确认流程。

## 减数策略

- 正式纳入普通周期、逐级减缓、人工减停、最后警告、待办、持久化通知和状态联动作业。
- 支持误记录撤回后的因果回放、补录重算、迁移基线校准、通知租约回收和周报审计。
- 减数策略仍由独立开关控制；从 `v1.0.1` 或更早版本首次启用前，必须按 `v1.0.2beta` 指南完成数据库副本预演、迁移和回滚校验。

## 群聊、记忆与萝卜猫

- 普通群消息可按配置概率自然接话，读取最近 30 分钟最多 20 条上下文，并识别发送者、艾特和引用方向。
- 成员记忆与接话概率解耦，只提炼本人明确表达、可回溯且非敏感的稳定特性，并生成服务器本地 JSON 镜像。
- 非业务点名或回复机器人时，业务识别保持最高优先级；只有未知意图才进入闲聊兜底。
- 萝卜猫只是角色名字，她不是猫，不自称猫或使用“喵”；她喜欢花和植物，并把“反二梦女”视为自己的兴趣和自我标签。
- 闲聊可按配置概率在同一条消息中附带表情包；业务回复永不附图。

## 私聊测试入口

- 新增与群业务隔离的私聊插件，只允许服务器私有配置中的精确 QQ号白名单。
- `PRIVATE_CHAT_ALLOWED_USER_ID` 支持使用英文逗号分隔多个 QQ号；真实白名单不会进入 GitHub。
- 允许账号的普通文字每条都会回复，最近 20 条双方消息只保存在内存中；命令、空消息和纯图片静默忽略。
- 私聊不执行查询、记录、禁言或减数操作，也不写群归档、成员记忆和违规数据库。

## 快速关闭

以下能力均可独立关闭，修改 `.env` 后重启 `qq-violation-bot.service` 生效：

```dotenv
RANDOM_CHAT_ENABLED=false
RANDOM_CHAT_DIRECT_FALLBACK_ENABLED=false
RANDOM_CHAT_STICKER_PROBABILITY=0
PRIVATE_CHAT_ENABLED=false
DEDUCTION_POLICY_V102_ENABLED=false
```

关闭任一入口不会删除违规记录、证据、记忆或审计数据。生产回滚前应先备份 `.env`、SQLite 数据库和 `data/` 运行目录。
