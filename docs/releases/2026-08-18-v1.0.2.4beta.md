# QQ 违规记录机器人 v1.0.2.4beta 更新公告

## 修复内容

- `查询 <群> <名字>` 现在会优先保留成员名并执行成员匹配。
- `查询 <群> <名字>违规记录` 不再忽略名字并返回该群最近 20 条记录。
- 模糊名字未找到时只返回一条补充 QQ号和昵称的提示；多人匹配时保持原有候选列表。
- `查询 <群> 违规记录` 继续返回分区记录，原功能不变。

## 影响范围

仅修改违规记录插件的查询意图快捷路由。不修改数据库、已有记录、记忆文件、随机接话概率或 OneBot/NapCat 登录状态。

## 回滚

本版本无数据迁移。恢复上线前备份的 `plugins/violation_record/ai_router.py` 并重启机器人服务即可回滚。
