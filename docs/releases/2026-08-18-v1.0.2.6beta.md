# v1.0.2.6beta 发布说明

发布日期：2026-08-18

## 萝卜猫闲聊

- 机器人闲聊身份为“萝卜猫”，自然可爱，喜欢花和植物。
- “反二梦女”仅作为名字或身份话题中的偶发玩笑，不作为固定自称或口癖。
- 普通未点名群消息以 3% 概率尝试接话；没有自然接话点时继续静默。
- 点名或回复机器人时，现有业务识别优先；只有 `unknown` 才转入闲聊回答。

非业务点名兜底由以下配置控制：

```dotenv
RANDOM_CHAT_DIRECT_FALLBACK_ENABLED=true
```

改为 `false` 并重启 `qq-violation-bot.service` 即可关闭该入口。普通 3% 接话、消息归档、成员记忆和全部业务功能不受此开关影响。

## 表情包

- 每次成功闲聊回复以 20% 概率附带最多一张表情包，文字和图片通过同一条 OneBot 消息发送。
- 第一张指定表情包在已决定附图后占 10%；剩余 57 张均分 90%，每张约 1.578947%。
- 表情包目录为 `data/random_chat/stickers/incoming/`，属于私有运行数据并由 Git 忽略。
- 业务回复不附带表情包；目录缺失、图片选择或发送异常不会改变业务数据。

生产配置：

```dotenv
RANDOM_CHAT_PROBABILITY=0.03
RANDOM_CHAT_STICKER_PROBABILITY=0.20
RANDOM_CHAT_SPECIAL_STICKER=5df2a91f55ea6257a768b6bcfe6a10b1.gif
```

## 实时记忆

成员记忆与回复概率彻底解耦。同一成员累计 5 条合格消息，或首条待处理消息等待 60 秒，任一条件满足即执行一次保守微批提炼。规则仍要求本人明确原话、可回溯消息和非敏感稳定特性；真实数据不进入 Git。

## 快速关闭与回滚

- 只关闭非业务点名闲聊：`RANDOM_CHAT_DIRECT_FALLBACK_ENABLED=false`。
- 只关闭表情包：`RANDOM_CHAT_STICKER_PROBABILITY=0`。
- 关闭全部普通随机接话：`RANDOM_CHAT_ENABLED=false`。

配置变更后重启机器人服务生效。本版本不迁移违规记录数据库；如需代码回滚，可切回 `v1.0.2.5beta`，私有表情包目录可保留。
