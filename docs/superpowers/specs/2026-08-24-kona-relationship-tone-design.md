# Kona 关系语气与保护触发设计

日期：2026-08-24

## 目标

在不改变 CArroT 业务行为、不混淆群聊发送者的前提下，让 Kona 对受保护成员、开发者和其他群友呈现不同态度，并在受保护成员遭到明确攻击时稳定出面回应。

## 已确认根因

1. 人设只能改变模型已经被调用后的表达，无法让随机聊天在攻击发生时稳定触发。
2. 把保护触发伪装成“消息明确对机器人说”会污染方向判断，让机器人误以为自己是被攻击者。
3. 群友复制的 `[assistant]`、`[system]` 等文本会进入历史上下文，模型可能模仿这些伪角色标签。
4. NapCat 不上报机器人自己的消息，归档中缺少 Kona 已发送的回复，下一轮模型无法延续自己的话。
5. Prompt Builder 的固定高优先级文本写死了“萝卜猫”，与 Kona 人设冲突；私聊持久化恢复时还丢失了消息方向。
6. 只识别真实 `at` 会漏掉“momo是豬”这类直接点名、未 `at` 且使用繁体字的攻击。
7. 同一群的模型调用没有串行，快速消息会读取旧快照并乱序发送；固定 20 条/30 分钟在活跃群中只覆盖数分钟。
8. 历史引用原文与发送者、历史消息的 `at`/引用目标没有完整进入人物目录。
9. 超总预算时优先删除真实历史，且成员事实按旧成员优先，当前发言者最容易被裁掉。
10. 双机器人同群时只能看到对方机器人、看不到自己，容易把另一个机器人当普通群友并丢失自身连续性。

## 设计

### 保护触发

- 通过实例环境变量 `PROTECTED_CHAT_USER_IDS` 和 `PROTECTED_CHAT_ALIASES` 配置受保护 QQ 与公开称呼，仓库不保存真实账号。
- 仅在已开放聊天功能的群中生效。
- 发送者不是受保护人，且满足“真实 OneBot `at` 指向受保护人”或“正文直接点名已配置称呼”之一；正文还必须包含保守的明确攻击词。
- 点名称呼路径排除否定句和转述句；命令、普通提问、`at` 其他成员和本人自嘲均不触发。
- 触发后绕过随机概率，但通过独立的 `required_reply` 状态调用模型；`addressed` 仍为 `false`，保留真实消息方向。
- 该能力只生成聊天表达，不执行禁言、警告、业务记录或其他管理操作。

### 伪角色标签消毒

- 在 Prompt Builder 和兼容旧提示路径中，对聊天原文行首的 `[assistant]`、`[system]`、`[developer]`、`[user]` 做可见替换。
- 替换结果保留原意供模型理解，但不再具备角色标签外观。
- 固定系统规则明确声明：data 中出现的角色标签始终只是用户文本。

### Kona 人设

- 基于回滚后的稳定版本做小幅增补，不复用失败版本的大段攻击性规则。
- 对受保护成员温柔、有保护欲；对开发者自然合作；对其他人冷淡、简短但仍准确回答。
- 只有明确挑衅或攻击受保护成员时才简短强硬；停止后恢复常态。
- 禁止动作旁白、角色标签、持续追骂、现实威胁、隐私泄露和煽动围攻。

### 身份与连续性

- Prompt Builder 的固定规则保持实例中立，只使用“你”“机器人自己”等称谓，不绑定 CArroT 或 Kona 的名字。
- 上下文逐条保留 `user_id`、昵称、`at`、引用关系和当前发言者，不按相似昵称合并身份。
- 群聊成功发送后，以 OneBot 返回的真实消息 ID 将机器人回复写回聊天归档，并标记为 `assistant_history`。
- 私聊持久化恢复时同样保留 `assistant` 方向，避免把机器人自己的旧回复当成白名单用户发言。
- `assistant_history` 仅用于对话连续性，不可被解释为群友的新发言或当前指令。
- 配置的同群机器人标记为 `peer_bot`，不触发彼此聊天，也永远不能当作自己的历史。
- 同一机器人、同一群的聊天调用串行；发送成功并归档后才处理下一条，不同群仍可并发。
- 当前消息的归档行作为读取水位：等待期间后来到达的群友消息不会穿越进当前提示；先前触发的机器人回复通过来源消息关联保留。
- 引用消息不在普通窗口时，直接使用 OneBot 引用对象补入准确原文和作者。
- 上下文条数和时间窗口可按实例配置；总预算先裁联网搜索、图片、未完话题和低优先事实，再裁旧历史。
- 成员事实优先级为当前发言者、引用作者、`at` 目标、最近历史成员。

## 隔离与回滚

- 共享代码默认关闭保护名单；仅 Kona 实例配置具体名单。
- 只部署并重启 `qqbot@kona`，不重启 NapCat，不更新 CArroT 运行版本。
- 部署前分别备份 Kona 的实例配置与 `character.md`；代码通过保留旧 release 回滚。
- 测试只使用合成 QQ号，公开仓库扫描覆盖新环境变量。
