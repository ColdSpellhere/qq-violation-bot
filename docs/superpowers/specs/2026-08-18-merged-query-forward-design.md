# 查询结果合并转发设计

## 目标

多条违规记录查询只在群里产生一张合并转发卡片，每条记录与它的证据图片保持在同一节点，避免逐条消息刷屏。

## 行为

- 两条及以上 `StructuredReply` 通过 `send_group_forward_msg` 一次发送。
- 每条 `RecordMessage` 转换为一个自定义节点，节点内按原顺序放置文字和存在的本地图片。
- 单条结果继续使用原普通图文消息，不增加额外点击。
- 合并转发失败时，只降级发送一条合并文字，并说明证据图片未展开；不逐条重发。

## 边界

不修改查询 SQL、排序、20 条上限、证据存储或数据库。导出、无记录和单条文本回复保持现状。

## 验证与回滚

测试覆盖多节点单次调用、图片顺序、缺失图片过滤、转发失败单消息降级和单条兼容。版本记为 `v1.0.2.5beta`；无数据迁移，回滚只需恢复发送层。
