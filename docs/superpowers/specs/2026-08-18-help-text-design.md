# 帮助文案重写设计

## 目标

将当前的平铺示例清单改为一条结构化管理手册，让管理员能直接复制常用命令，并理解参数、确认流程和高风险操作的边界。

## 内容结构

1. 使用前说明：需要 @机器人，群域限定为蜂巢/蜂窝/蜂箱，成员查询和减数命令的目标格式不同。
2. 常用查询：按昵称、QQ号、成员最近记录、分区时间范围和导出。
3. 新增违规记录：完整示例、引用消息时间。
4. 群管理：@ 或 QQ号禁言，明确为立即操作。
5. 状态与记录维护：质询、最后警告、撤回、退群/移出/拉黑和解锁。
6. 减数策略：先列查询，再列必须包含群域、QQ号和事由的写命令。
7. 确认与取消：说明除群禁言外的写操作会先预览。

## 边界

只重写 `HELP_TEXT`，不新增帮助分页、命令别名或业务路由。帮助中只提供当前代码已支持的命令。

与查询合并转发功能一起记录为 `v1.0.2.5beta`。
