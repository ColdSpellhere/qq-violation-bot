# Kona 关系语气完整修复实施计划

**目标：** 修复受保护成员被攻击时不稳定接话，以及复制模型文本污染群聊方向的问题；仅在 Kona 上启用保护名单。

## 1. 回归测试

- [x] 策略测试覆盖真实 `at` + 明确攻击、普通 `at`、无 `at`、其他目标、命令和本人消息。
- [x] 群路由测试证明保护触发绕过概率，普通消息继续受概率控制。
- [x] Prompt Builder 测试证明伪角色标签被消毒。
- [x] 测试证明保护回复不会把消息伪装成对机器人说。
- [x] 兼容旧提示路径具备相同的方向与消毒边界。
- [x] 直接称呼 + 繁体攻击词可触发，否定句和转述句不会误触发。
- [x] 群聊发送成功后归档自身回复，归档失败不影响后续回复发送。
- [x] 群聊与私聊的机器人旧回复均以 `assistant_history` 注入。
- [x] Prompt Builder 的群聊与私聊固定规则均不写死实例身份。
- [x] 同群模型调用按实例和群号串行，发送成功后回写自身历史。
- [x] 用当前消息归档水位排除等待期间的未来消息，并保留先前机器人回复。
- [x] 引用窗口外消息时补入 OneBot 原文和准确作者。
- [x] 同秒消息按数据库接收顺序稳定排序。
- [x] 当前成员记忆优先于旧成员；历史 `at`/引用目标进入人物目录。
- [x] Prompt 超预算时先裁可选辅助数据，保留最近核心对话。
- [x] 同群另一个机器人标记为 `peer_bot` 且不互相触发。

## 2. 最小实现

- [x] 增加默认空的 `PROTECTED_CHAT_USER_IDS` 实例配置。
- [x] 增加纯函数保护策略，不引入业务动作。
- [x] 增加独立 `required_reply` 状态并贯穿群路由、模型调用和 Prompt Builder。
- [x] 增加角色标签消毒器并覆盖新旧提示路径。
- [x] 增加默认空的 `PROTECTED_CHAT_ALIASES`，并保守识别直接点名攻击。
- [x] 使用真实 OneBot 消息 ID 归档成功发出的群聊回复。
- [x] 保留私聊持久化消息的机器人方向。
- [x] 上下文条数与时间窗口支持实例配置。
- [x] 上下文数据库异常记录可观测的脱敏错误类型。
- [ ] 运行完整测试、编译检查和公开仓库扫描。

## 3. Kona 生产更新

- [x] 备份 Kona `.env`、`character.md` 和当前 release 指向。
- [x] 在 Kona 实例配置受保护成员，不向仓库写入真实 QQ号。
- [x] 基于稳定版 `character.md` 做小幅关系语气增补并原子替换。
- [x] 生成不可变代码快照，仅更新并重启 `qqbot@kona`。
- [x] 验证 Kona 服务、OneBot 连接、加载配置和近期日志；确认 CArroT release 与服务未变化。
- [ ] 部署身份与连续性修复，仅更新并重启 `qqbot@kona`。
- [ ] 用新消息验证自身回复开始进入 Kona 归档。

## 4. 回滚

- 代码异常：把 Kona `current` 恢复到部署前 release，重启 `qqbot@kona`。
- 人设异常：原子恢复部署前 `character.md`，无需重启。
- 触发策略异常：清空 Kona 的 `PROTECTED_CHAT_USER_IDS` 与 `PROTECTED_CHAT_ALIASES` 并重启 `qqbot@kona`。
