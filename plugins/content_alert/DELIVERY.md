# 关键词告警投递与恢复

此模块仅产生管理群告警，不撤回、禁言或写入违规记录。人工、legacy、managed 的词条规范化、最长匹配优先、同长次序、文本段隔离、受保护内容隐藏规则保持不变；不修改实际词库或 immutable generation。

## 投递保证

告警在首次发送前，先将已渲染、已脱敏且长度受限的报告提交至实例 `data/content_alert/outbox.sqlite3`。数据库不保存原始事件、完整正文、实际词库或模型输入；报告可能包含既有披露规则允许的短摘录和发送者标识，应按私有运行数据管理，禁止提交到源码仓库。

- 完整事件键为 `SHA-256(self_id:group_id:message_id)`，稳定告警号为 `KA-` 加前 12 位。数据库唯一约束跨进程重启去重，重试保留同一编号和原报告。
- 规则版本保存本次 managed snapshot 的 generation ID，以及人工、legacy 规则快照摘要。人工规则原文不进入版本字段，重试不重新解释新词库。
- `pending → leased → sending → delivered`。未开始发送的租约到期可重新排队；已进入发送阶段的租约到期变为 `delivery_unknown`，不自动重发。租约 90 秒，发送超时 30 秒，发送记录附带租约令牌，过期持有者不能覆盖新状态。
- 明确的 OneBot `ActionFailed` 拒绝触发指数退避，自动发送最多 5 次，达到上限为 `exhausted`。后台 worker 每 2 秒检查队列，每个 Bot 每轮最多处理 10 条，无需再次收到原消息。
- 网络异常、超时、取消、无有效消息回执，以及远端成功后本地确认写入失败，都不证明消息未送达。此类状态保留为未知，等待人工核对；未知状态没有自动重试。
- 成功响应及有效消息 ID 只证明 OneBot 接受发送，不证明管理员已经阅读。QQ 发送与 SQLite 事务不能原子提交，因此不承诺 exactly-once，也不承诺所有输入必定产生告警；可靠恢复从 outbox 提交成功开始。

每次领取后、进入发送状态后、实际发送协程开始时都会重验运行期开关、当前实例身份及来源/报告群。关闭功能或关停阻止后续调用，不能撤销已经进入 QQ API 的请求。持久任务在重新启用后不受新事件的 300 秒时效过滤影响。

## 人工核对

沿用现有超级管理员权限、私聊/管理群寻址边界。状态命令不显示报告、正文、词库内容或 generation 元数据。

```text
/违禁词 告警状态
/违禁词 告警状态 KA-0123456789ab
/违禁词 告警重试 KA-0123456789ab 确认
/违禁词 告警已收 KA-0123456789ab 确认
```

总览列出状态数量以及最多 10 个待人工处理的告警号。仅 `delivery_unknown` / `exhausted` 可以人工处理，操作人、动作和时间写入审计表。重试前先在管理群按告警号核对，原发送可能已经成功，再发可能重复。人工确认重试授予新的最多 5 次明确失败尝试预算；功能关闭时禁止重新排队。`告警已收` 只记录人工核实，不再次发送。

## 资源边界

人工和 legacy 每个规则源采用与 managed 相同量级的预算：输入/规范化文本单段最多 16,384 字符，整条消息原始文本总计最多 16,384 字符，最多 256 个消息段、20,000 个候选命中。超预算发出隐藏正文的扫描保护告警，不声称具体词条命中。

编译结果按完整人工规则快照作 16 项 LRU 缓存，规则改变自然失效。扫描放在线程中，最多同时执行 2 个、接纳 8 个事件。接纳队列满时至多允许一个隐藏保护告警入库，额外过载事件不继续分配等待任务。未投递/待人工处理任务总计最多 10,000 条，满额明确失败，不覆盖旧意图。该边界保护服务资源，不等于输入洪峰下零丢告警。

数据库权限为 `0600`，拒绝符号链接和多硬链接文件。已完成去重记录目前不自动清理；无限期运行需要按保留期设计归档和告警号去重策略，删除 ledger 会失去对应历史的重启去重能力。备份应使用 SQLite backup API 或停写一致性副本，覆盖此实例目录，不能仅依赖旧业务库备份。

## 回归范围

本地合成数据与假 Bot 覆盖：重启去重、明确拒绝退避、未知结果不自动重放、租约恢复/旧持有者、运行期开关竞态、关停、身份边界、消息回执验证、回执落库失败、人工权限/确认审计、容量与文件保护、generation 留痕与持久化脱敏、扫描预算/事件循环隔离，以及 200 组固定随机输入对旧最长匹配算法的行为对照。既有受控目录、导入、报告和插件加载回归一起执行；测试不访问 QQ、外部模型或生产数据。
